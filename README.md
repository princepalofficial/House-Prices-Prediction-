House Price Prediction

About Project

This project analyzes house-related data and estimates house prices using Python, NumPy, and Pandas.

Project Objective

The objective is to understand house price factors, explore house data, perform feature engineering, and calculate estimated house prices using a predefined formula.

Technologies Used

- Python
- NumPy
- Pandas

Dataset

This project generates a synthetic dataset containing 1,000 house records.

The dataset includes:

- House ID
- Area in square feet
- Number of bedrooms
- Number of bathrooms
- House age
- Parking spaces
- Location score
- House price

Project Features

- Synthetic data generation
- DataFrame creation using Pandas
- Data inspection and statistical analysis
- Missing value and duplicate checks
- Average house price calculation
- Feature engineering
- Price per square foot calculation
- Group-wise price analysis
- Formula-based house price estimation
- Mean Absolute Error (MAE) calculation

How House Prices Are Calculated

House prices are estimated using a predefined formula based on area, bedrooms, bathrooms, parking, location score, and house age.

Random noise is added to the generated prices to simulate variation in house prices.

Note: This project currently uses a predefined formula and synthetic data. It does not train a Machine Learning model.

How to Run

1. Install Python.

2. Install the required libraries:
   
   "pip install -r requirements.txt"

3. Run the Python file:
   
   "python "House price prediction.py""

Output

The program displays house data, data types, missing value counts, duplicate counts, descriptive statistics, average price, feature engineering results, group-wise price analysis, and price estimation results.
